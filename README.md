# Git in the age of AI: workshop

This repository is the hands-on part of the guest lecture "Git in the age of AI" at the University of Sheffield.

You will make your own copy of this repository, add a file to it, and save that change back to GitHub. Everything runs in your browser, so you do not need to install anything.

## Before you start

You need a GitHub account. If you do not have one, create it at [github.com/signup](https://github.com/signup) and verify your email address, then sign in.

## The exercise

1. **Fork this repository.** Click **Fork** at the top right of this page, then **Create fork**. You now have your own copy under your username.
2. **Open a codespace.** In your fork, click the green **Code** button, open the **Codespaces** tab and click **Create codespace on main**. A full editor (VS Code) opens in your browser. The first start can take a minute.
3. **Create your file.** In the file explorer on the left, right-click the `students` folder and choose **New File**. Name it after your GitHub username, for example `students/your-username.md`.
4. **Write a few lines.** For example:
   - your name and programme
   - one task you would ask an AI agent to do for you at work
   - one thing that would worry you about letting it do that task
5. **Commit your change.** Open the **Source Control** panel (the branch icon on the left). Type a short message such as `Add my introduction` and click **Commit**. If you are asked whether to stage your changes, choose **Yes**.
6. **Push your change.** Click **Sync Changes** (or **Push**). This sends your commit from the codespace to your fork on GitHub.
7. **Check your work.** Go back to your fork on github.com and open the `students` folder. Your file should be there, with your commit message next to it.

## Words you will meet

| Term | What it means |
| --- | --- |
| Repository | A project folder that Git keeps the full history of |
| Fork | Your own copy of someone else's repository on GitHub |
| Codespace | A ready-made computer in the cloud with an editor and Git installed |
| Commit | A saved snapshot of your changes, with a message explaining them |
| Push | Sending your commits from your computer (here, the codespace) to GitHub |
| Pull | Bringing the latest commits from GitHub to your computer |

## If something goes wrong

- **The Fork button does nothing:** check that you are signed in.
- **The codespace will not start:** refresh the page and try again, or delete it at [github.com/codespaces](https://github.com/codespaces) and create a new one.
- **Push is rejected:** make sure you opened the codespace from *your fork*, not from the original repository. The URL should contain your username.

## When you finish

Codespaces use your free monthly allowance while they run. Go to [github.com/codespaces](https://github.com/codespaces), and stop or delete the codespace you created today.
